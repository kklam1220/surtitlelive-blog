# Blog article localization briefs

Files in this directory are editorial transcreation briefs for claim-sensitive or culture-sensitive blog posts.

They do not replace the English Markdown source of truth. They document how future locale work should preserve product truth while adapting examples, idiom, family relationships, education vocabulary and cultural framing for the target readership.

For a briefed article:
1. keep English Markdown canonical;
2. treat an explicitly approved manual locale payload as authoritative for that locale;
3. keep other locales deferred until a native-quality transcreation uses the matching brief;
4. localize illustrative language examples so the target locale is represented naturally rather than copying an unrelated source example;
5. preserve the product-claim limits in the brief exactly even when prose, examples or sentence structure change.

The current blog translation script already requires first-class locale copy and localized illustrative examples. These briefs add article-specific editorial guidance for human or AI-assisted review; they are not a second translation engine.
